# Exchange Calendar (EWS) для Home Assistant

[![Открыть репозиторий в HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=he110&repository=ha-ews-calendar&category=integration)
[![Добавить интеграцию Exchange Calendar.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=ews_calendar)

Подключает календари **корпоративного (on-prem) Microsoft Exchange Server** к Home Assistant
как обычные сущности `calendar` через Exchange Web Services (EWS).

Работает там, где обычный обходной путь закрыт: многие компании запрещают публиковать
календари ICS-ссылкой, но оставляют EWS — тот же API, которым пользуются Outlook для Mac и
мобильные почтовые клиенты.

[English version](README.md)

## Возможности

- Свой календарь и **общие календари** других ящиков, к которым у вас есть доступ (коллеги,
  переговорные, общие ящики команды).
- Авторизация **NTLM** (в том числе с **Extended Protection** / channel binding) и **Basic** —
  выбирается автоматически.
- Повторяющиеся встречи Exchange разворачивает сам; перенесённое вхождение сохраняет
  идентичность (`uid` + `recurrence_id`) — другие интеграции видят его как изменение, а не новое событие.
- Описания встреч текстом — обычно там ссылка на Teams/Zoom.
- Скрывает отклонённые вами и отменённые встречи (настраивается).
- Работает с самоподписанными и внутренними сертификатами (по желанию).
- Повторный вход при смене пароля, перенастройка без переподключения, диагностика без секретов.
- Только чтение. В ящик ничего не пишется.

## Требования

| | |
|---|---|
| Exchange | **Exchange Server 2013, 2016, 2019 или Subscription Edition**, on-prem, EWS доступен из сети Home Assistant |
| Home Assistant | 2026.2 и новее |
| Не поддерживается | **Exchange Online / Microsoft 365** — там Microsoft отключил вход в EWS по паролю, нужен OAuth |

EWS должен быть включён для вашего ящика. Если нет — сервер отвечает `403`, интеграция об этом сообщит.

## Установка

**HACS (рекомендуется):** кнопка **Open in HACS** вверху (или HACS → ⋮ → Custom repositories →
`https://github.com/he110/ha-ews-calendar`, категория *Integration*), установить, перезапустить Home Assistant.

**Вручную:** скопировать `custom_components/ews_calendar` в `config/custom_components/` и перезапустить.

## Настройка

Кнопка **Add integration** вверху или *Настройки → Устройства и службы → Добавить интеграцию →
Exchange Calendar (EWS)*.

| Поле | |
|---|---|
| Сервер | Имя хоста (`mail.example.com`) или полный адрес EWS (`https://mail.example.com/EWS/Exchange.asmx`) |
| Логин | Обычно адрес почты или `ДОМЕН\логин` |
| Пароль | Пароль от почты |
| Авторизация | «Автоматически» — NTLM, если сервер его предлагает, иначе Basic |
| Проверять SSL-сертификат | Выключайте только для самоподписанных или внутренних сертификатов |

Свой календарь добавляется сразу. Чтобы добавить чужой — откройте интеграцию →
**Добавить общий календарь** и укажите адрес ящика. Нужно право хотя бы на чтение — то же,
что нужно, чтобы открыть этот календарь в Outlook.

> **Важно:** повторные неверные пароли могут заблокировать учётную запись. Если форма
> говорит, что пароль отклонён, сначала проверьте его входом в Outlook в браузере.

## Параметры

*Настройки → Устройства и службы → Exchange Calendar → Настроить* — действуют на все календари учётной записи.

| Параметр | По умолчанию | |
|---|---|---|
| Интервал обновления | 10 мин | Не меньше 5 |
| Сколько дней вперёд держать в кэше | 30 | Дальше — подгружается по запросу, например при листании календаря |
| Загружать описания | вкл | Один дополнительный запрос на 50 событий |
| Скрывать отклонённые мной встречи | вкл | |
| Скрывать отменённые встречи | вкл | Отменённые встречи висят в Outlook, пока их не удалишь |

## Использование

Каждый календарь — обычный календарь Home Assistant: виден в панели «Календарь», состояние `on`
во время события, работает с [calendar-триггером](https://www.home-assistant.io/docs/automation/trigger/#calendar-trigger).
Пример напоминания — в [английском README](README.md#using-it).

## Безопасность

- Пароль хранится в настройках интеграции Home Assistant, как учётные данные любой другой
  интеграции. **Во многих компаниях есть правила о хранении корпоративных паролей на личных
  устройствах — проверьте их заранее.**
- При NTLM сам пароль по сети не передаётся.
- Интеграция только читает календарь и обращается только к вашему серверу Exchange. Данные
  не покидают ваш Home Assistant.
- В диагностике скрыты адрес сервера, логин, пароль и адреса ящиков.

## Если не работает

| Симптом | Что проверить |
|---|---|
| «Сервер отклонил логин или пароль» | Вход в Outlook в браузере с теми же данными. Попробуйте `ДОМЕН\логин` вместо адреса почты. |
| «Не удалось достучаться до EWS» | Откройте `https://ваш-сервер/EWS/Exchange.asmx` в браузере из той же сети, что и Home Assistant, — должен появиться запрос логина. |
| `HTTP 403` в журнале | EWS выключен для ящика (для администратора: `Get-CASMailbox <user> \| fl EwsEnabled`). |
| «Не удалось проверить сертификат» | Внутренний CA или самоподписанный сертификат — выключите проверку SSL. |
| События на весь день съехали на день | У Home Assistant и ящика разные часовые пояса. |
| Другое | *Устройства и службы → Exchange Calendar → ⋮ → Скачать диагностику* и приложите к [issue](https://github.com/he110/ha-ews-calendar/issues). |
